### 1. Assessing Automotive Efficiency: Technology Gains vs. Vehicle Size (1975–2025)

[View the project repository](https://github.com/abidurrahman2025/automotive-efficiency-trends.git)

This data analysis project investigates whether the shift toward larger vehicles reduced the fuel-efficiency gains achieved through automotive technology improvements from 1975 to 2025. Using EPA fuel economy data and vehicle class summaries, the analysis compares how efficiency changed across passenger cars, SUVs, and trucks over time.

The analysis includes:

- MPG distributions across cars, SUVs, and trucks
- Changes in vehicle-class composition over time
- The relationship between engine displacement and combined MPG
- Gasoline and diesel efficiency trends from 1975 through 2025
- Density plots, stacked bar charts, scatterplots, and trend-line comparisons

**Tools:** Python, `pandas`, `NumPy`, `matplotlib`, `seaborn`, and data visualization

### 2. 2025 Vehicle Fuel Economy Analysis

[View the project repository](https://github.com/abidurrahman2025/2025-vehicle-fuel-economy-analysis.git)

This project analyzes 2025 model-year fuel economy data from FuelEconomy.gov to evaluate how aspiration type, fuel type, engine displacement, and drivetrain relate to city, highway, and combined MPG. It combines descriptive statistics, hypothesis testing, and regression modeling to assess which variables meaningfully explain variation in fuel efficiency across the vehicle fleet.

The analysis includes:

- Data collection and cleaning from EPA and DOE fuel economy data
- Descriptive statistics and exploratory visualization
- Welch t-tests for pairwise comparisons
- Two-way ANOVA and interaction analysis
- Correlation analysis
- Multiple linear regression and model diagnostics
- Interpretation of confounding effects and model assumptions

The results show how engine size and vehicle configuration influence efficiency and highlight how accounting for confounding variables changes the interpretation of fuel type and aspiration effects.

**Tools:** Python, `pandas`, `NumPy`, `matplotlib`, `scipy`, `statsmodels`, `openpyxl`, and statistical modeling

### 3. Real-time Currency Volatility Dashboard

[View the project repository](https://github.com/abidurrahman2025/Real-time-Currency-Volatility-Dashboard)

This Python and Plotly Dash application provides an interactive view of short- and medium-term volatility across currency pairs. It is designed for traders, analysts, and researchers who need an accessible way to monitor changing market conditions and compare volatility behavior over time.

Key capabilities include:

- Configurable real-time or frequently refreshed FX quote ingestion
- Log-return and rolling-volatility calculations
- Realized-volatility analysis
- Interactive time-series charts and volatility heatmaps
- Currency-pair selection and comparison
- Threshold-based alerts and optional webhooks
- CSV export of market snapshots and charts

The project demonstrates how financial time-series analytics can be combined with an interactive dashboard for market monitoring and decision support.

**Tools:** Python, Plotly Dash, Pandas, NumPy, APIs, and time-series analytics
